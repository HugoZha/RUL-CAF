\paragraph{Data availability}
The NASA C-MAPSS turbofan engine degradation simulation data analysed in
this study are a U.S.\ Government work in the public domain, distributed by
the NASA Prognostics Data Repository. We acknowledge the repository and the
data donors, and cite the source dataset as Saxena and Goebel (2008). The
processed experiment scripts, aggregate results, training logs, per-epoch
records and checkpoint features that support the findings of this paper,
together with the C-MAPSS subset files used, are available in the tagged
release \texttt{data-v1} of the project repository at
\url{https://github.com/HugoZha/RUL-CAF/releases/tag/data-v1}.
